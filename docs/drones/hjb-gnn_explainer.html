Safe Multi-Agent Navigation via Constrained HJB-Informed Learning

Many drones must reach their goals without crashing. The two aims fight each other. This paper (HJB-GNN) solves both in one problem and gets a closed-form dial, λ, that mixes goal-reaching and safety on its own.

1 · The problem

Old methods bolt safety on top of a fixed goal controller

Before: QP-GCBF

Now: HJB-GNN

2 · Setup

Each drone sees only a small graph around it

Agent dynamics

$$\dot x_i = f(x_i) + g(x_i)\,u_i$$

Goal error and stage cost

$$e_i = p_i - p_i^{g},\qquad r_i = e_i^\top Q e_i + u_i^\top R u_i$$

Example: a drone 2 m from its goal pays more than one 0.5 m away; fast, hard moves also cost more.

Graph control barrier function (CBF) h

A learned score: h ≥ 0 means safe, h < 0 means unsafe. The rule below says h may fall only slowly near the edge, so the drone can never cross it.

$$\dot h(\bar x_{\hat{\mathcal N}_i}) \;=\; \sum_{l\in\hat{\mathcal N}_i^{a}} \nabla_{x_l}h\,\big(f(x_l)+g(x_l)u_l\big)\;\ge\; -\alpha\big(h(\bar x_{\hat{\mathcal N}_i})\big)$$

Sum runs over the drone and its neighbours. Example: if h = 0.4 and α(h) = h, then h may shrink by at most 0.4 per second.

3 · The key math

From one optimisation problem to a closed-form controller

1

One problem for both goals

$$\min_{u_i}\int_{t_0}^{\infty} r_i(e_i,u_i)\,d\tau\quad\text{s.t.}\quad \dot x_i=f+gu_i,\;\; \dot h+\alpha(h)\ge 0$$

Cost to reach the goal forever, with safety as a hard rule.

2

HJB equation: the best cost-to-go V* obeys

$$0=\min_{u_i} H_i,\qquad H_i=\nabla_{e_i}V_i\,\big(f+gu_i\big)+r_i(e_i,u_i)$$
3

Add the safety rule at each instant

$$\min_{u_i} H_i\quad\text{s.t.}\quad \dot h+\alpha(h)\ge 0$$

Both parts are convex in u, so KKT conditions are enough to find the optimum.

4

KKT conditions, with multiplier λ

$$\begin{aligned}\nabla_{u}H_i-\lambda_i^*\nabla_{x_i}h\,g&=0 &&\text{(stationary)}\\ \lambda_i^*\big(\dot h+\alpha(h)\big)&=0 &&\text{(slackness)}\\ \dot h+\alpha(h)&\ge 0,\;\;\lambda_i^*\ge 0\end{aligned}$$
5

Solve the first line for u

$$u_i^*=-\tfrac12R^{-1}g^\top(x_i)\Big(\underbrace{\class{goal-t}{\nabla_{e_i}^\top V_i^*}}_{\text{goal}}\;-\;\lambda_i^*\,\underbrace{\class{safe-t}{\nabla_{x_i}^\top h}}_{\text{safety}}\Big)$$

The dial λ*

Plug u* into ḣ + α(h). It equals Λ + λω. Slackness sets it to 0 when the constraint is tight, so:

$$\lambda_i^*=\begin{cases}-\Lambda_i/\omega_i & \Lambda_i<0\\[2pt] 0 & \Lambda_i\ge 0\end{cases}\;=\;\max\!\big(0,\,-\Lambda_i/\omega_i\big)$$
  • Λ: safety margin if the drone only chases its goal. Λ < 0 means the goal move is unsafe.
  • ω > 0: how strongly the control can change h.

Why this helps

  • Neighbours far away: Λ ≥ 0, so λ = 0 and the drone flies the pure goal-optimal path.
  • A neighbour gets close: Λ drops, so λ switches on exactly as much as needed.
  • No hand-tuned weight, no gradient projection, no extra variable.
Theorem 1. If V* is smooth and h is a valid graph CBF (with ‖∇h·g‖ ≥ ϱ > 0), then u* with λ* from the formula above gives, for any number of drones: (i) safe: the state stays in the safe set for all time, and (ii) goal reached: each error ei(t) → 0.

5 · Learning it

Three networks replace the three things we cannot compute

Obstacle to the formulaFix
λ* needs neighbours' controls, so it is not distributedA GNN policy πφ learns to imitate the formula using only the local graph
True value function V* is unknownA small MLP Vθ(e), trained to satisfy HJB
No hand-made h in unknown scenesA GNN hϑ learned from safe / unsafe samples

Training is centralised (one computer sees all drones). At run time each drone runs only its own πφ on its local graph.

Three losses, one per network

Value Vθ

$$\mathcal L_v=b_{1}\max\!\big(0,\alpha_1(\|e\|)-V_\theta\big)+b_{1}\max\!\big(0,V_\theta-\alpha_2(\|e\|)\big)+b_{2}\,\delta^2$$
$$\delta=\nabla_{e}V_\theta\,(f+g\pi_\phi)+r$$

First two terms keep V positive and bounded (a Lyapunov function). δ is the Bellman error; zero means HJB holds.

Graph CBF hϑ

$$\mathcal L_h=\sum_{\text{safe}}\max(0,\varsigma-h_\vartheta)+\sum_{\text{unsafe}}\max(0,\varsigma+h_\vartheta)+b_h\sum\max\!\big(0,\varsigma-\dot h_\vartheta-\alpha(h_\vartheta)\big)$$

Safe samples get h > 0, unsafe get h < 0, and the decay rule (4) holds.

Policy πφ

$$\mathcal L_u=\underbrace{b_\pi\|\pi_\phi(\eta_i)-\hat u_i\|}_{\text{imitate formula}}+\mathcal L_h+\mathcal L_{v}^{\delta}$$
$$\hat u_i=-\tfrac12R^{-1}g^\top\big(\nabla^\top V_\theta-\hat\lambda_i\nabla^\top h_\vartheta\big)$$

The policy copies the KKT formula, so it inherits the adaptive λ.

Training loop (Algorithm 1)

Warm-upTrain Vθ aloneGives a first admissible policy.
→
Each iterationCollect dataRun πφ to get safe / unsafe samples; sample random states.
→
Phase 1 · evaluateπ fixedUpdate Vθ and hϑ until the Bellman error drops.
→
Phase 2 · improveV fixedUpdate πφ and hϑ until V̇ < 0 (stabilising).
↺

Same idea as policy iteration: evaluate the current policy, then improve it, and repeat.

7 · Summary

What to remember

One problem, not two layers

Goal and safety sit in a single infinite-horizon problem, so the controller looks far ahead instead of one step.

λ* sets the balance

The KKT answer λ* = max(0, −Λ/ω) turns safety on only when the neighbours need it.

Local at run time

A GNN policy imitates the formula from local data. Trained on 8 drones, it ran on up to 1024.

Limits noted in the paper. Tests compare against one baseline (QP-GCBF+). On the real drones the policy ran off-board on a PC. The policy was trained with static obstacles only, and obstacle velocity is not used.

Learn how wrong the model is, then patch the safety rules

Choi, Castañeda, Tomlin, Sreenath. Reinforcement Learning for Safety-Critical Control under Model Uncertainty, using Control Lyapunov Functions and Control Barrier Functions

Problem

The controller's safety math uses a model of the robot. If the model is wrong, a "safe" command can be unsafe.

Idea

In every rule, the model error has the form offset + slope × µ. A neural network learns those two terms (β, α).

Result20 / 20 steps

on the stones with the fix. Without it: first miss after 5.6 steps on average.

Catch

The starting controller must not fall at once, or there is no data to learn from.

The whole method

One picture, one equation

eq. 45 · RL-CBF-CLF-QP \[ \begin{aligned} \mu^*_{\class{mx-rl}{\theta}}(x) = \underset{\mu,\ \mu_b,\ d}{\arg\min}\ \ & \mu^\top\mu + p\,d^2 \\ \text{s.t.}\ \ & \class{mx-clf}{\hat{\dot V}_{\varepsilon,\class{mx-rl}{\theta}}(\eta,z,\mu) + \tfrac{\lambda}{\varepsilon}V_\varepsilon(\eta) \le d} && \class{mx-clf}{\text{stability}} \\ & \class{mx-cbf}{\mu_{b,i} + K_{b,i}\,\eta_{b,i} \ge 0,\ \ \mu_{b,i} = \widehat{B_i^{(r_b)}}_{\class{mx-rl}{\theta}}(x,\mu)} && \class{mx-cbf}{\text{safety}} \\ & A^c_{j,\class{mx-rl}{\theta}}(x)\,\mu + b^c_{j,\class{mx-rl}{\theta}}(x) \le 0 && \text{friction} \end{aligned} \]

Pick the smallest µ that passes every rule. Each hat (^) term = model's value + learned patch (θ). Stability may bend by a slack d, which costs p·d². Safety may not bend.

Background you need

Four building blocks

modelThe model vs. the real robot

\[ \begin{aligned} \text{model:}\ \ \dot x &= \tilde f(x) + \tilde g(x)\,u \\ \text{real:}\ \ \dot x &= f(x) + g(x)\,u \end{aligned} \] \[ \begin{aligned} \text{ask for } \mu \text{, model promises:}\ \ y^{(r)} &= \mu \\ \text{real gives:}\ \ y^{(r)} &= \mu + \class{mx-bad}{\Delta_1(x) + \Delta_2(x)\,\mu} \end{aligned} \]

µ = the joint acceleration the controller asks for. r = how many times you differentiate the output before the torque shows up (angle → speed → acceleration, so r = 2).

rough illustration: robot 2× heavier → ask µ = 1.0 rad/s², get ≈ 0.5 rad/s² (Δ₂ ≈ −0.5)

CLFStability rule

\[ V_\varepsilon(\eta) = \eta^\top P_\varepsilon\,\eta \qquad \class{mx-clf}{\dot V_\varepsilon + \tfrac{\lambda}{\varepsilon}\,V_\varepsilon \le 0} \]

η = tracking error and its rate. V = one number for "how far off the planned gait". The rule: V must shrink at least this fast.

λ/ε = 10, V = 0.5 now → need V̇ ≤ −5 per second

CBFSafety rule

\[ B(x) \ge 0 \iff \text{safe} \qquad \class{mx-cbf}{\ddot B + k_1 \dot B + k_0 B \ge 0} \] \[ \text{paper: } \class{mx-cbf}{\mu_b + K_b\,\eta_b \ge 0}, \quad \mu_b = B^{(r_b)} \]

B = safety margin. The rule limits how fast B may head toward 0, so it never crosses.

foot must land past l_min = 0.35 m → B₁ ≈ l − 0.35 ≥ 0 (simplified)

QPThe referee: a quadratic program

\[ \begin{aligned} \min_{\mu,\,\mu_b,\,d}\ \ & \mu^\top\mu + p\,d^2 \\ \text{s.t.}\ \ & \class{mx-clf}{\dot V_\varepsilon(\eta,\mu) + \tfrac{\lambda}{\varepsilon}V_\varepsilon \le d} \\ & \class{mx-cbf}{\mu_b + K_b\,\eta_b \ge 0} \\ & A_c(x)\,\mu + b_c(x) \le 0 \end{aligned} \] eq. 18 · CBF-CLF-QP

Every rule is a straight line in µ, so this solves fast enough to rerun every 10 ms. Last line = friction: |FT/FN| ≤ 0.8 and FN ≥ 0 (foot pushes, never pulls).

The problem

A wrong model moves every rule line

eqs. 31, 35, 41 \[ \begin{aligned} \underbrace{\class{mx-clf}{\dot V_\varepsilon}}_{\text{real}} &= \underbrace{\tilde{\dot V}_\varepsilon}_{\text{model predicts}} + \underbrace{\class{mx-bad}{\Delta^V_1 + \Delta^V_2\,\mu}}_{\text{unknown error}} \\[4pt] \class{mx-cbf}{B^{(r_b)}} &= \widetilde{B^{(r_b)}} + \class{mx-bad}{\Delta^b_1 + \Delta^b_2\,\mu} \\[4pt] \zeta &= \tilde\zeta + \class{mx-bad}{\Delta^c_1 + \Delta^c_2\,\mu} \end{aligned} \]

Key fact: the error is always offset (Δ₁) + slope × µ (Δ₂). So it shifts and tilts each rule's line, but the line stays straight. ζ = any other rule, like friction.

The fix

Learn the offset β and slope α for each rule

eqs. 32, 38, 43 \[ \begin{aligned} \class{mx-clf}{\hat{\dot V}_{\varepsilon,\theta}} &= \tilde{\dot V}_\varepsilon + \class{mx-rl}{\beta^V_\theta(x) + \alpha^V_\theta(x)\,\mu} \\[4pt] \class{mx-cbf}{\widehat{B^{(r_b)}}_\theta} &= \widetilde{B^{(r_b)}} + \class{mx-rl}{\beta^B_\theta(x,\psi) + \alpha^B_\theta(x,\psi)\,\mu} \\[4pt] \hat\zeta_\theta &= \tilde\zeta + \class{mx-rl}{\beta^C_\theta(x) + \alpha^C_\theta(x)\,\mu} \end{aligned} \]

Goal: make each \(\class{mx-rl}{\beta}\) match Δ₁ and each \(\class{mx-rl}{\alpha}\) match Δ₂. The patched rule is still a straight line in µ, so the QP stays a QP. ψ = the next stone's l_min, fed to the network.

eqs. 46–48 · reward \[ R = -\,w_v \big\| \underbrace{\dot V_\varepsilon}_{\text{measured}} - \underbrace{\class{mx-rl}{\hat{\dot V}_{\varepsilon,\theta}}}_{\text{predicted}} \big\|^2 \;-\; \sum_i w_{b,i} \big\| B_i^{(r_b)} - \class{mx-rl}{\widehat{B_i^{(r_b)}}_\theta} \big\|^2 \;-\; \sum_j w_{c,j} \big\| \zeta_j - \class{mx-rl}{\hat\zeta_{j,\theta}} \big\|^2 \;-\; \underbrace{l_e(x)}_{\text{fall penalty}} \] \[ \max_{\class{mx-rl}{\theta}}\ \mathbb{E}\Big[\int_0^T R\big(x(\tau),\theta\big)\,d\tau\Big], \qquad \text{robot driven by } \mu^*_\theta + w,\ \ w \sim \mathcal N(0,\sigma^2) \]

No true model needed: "measured" values come from numerical derivatives of V, B and the contact forces. Noise w makes the robot try new things.

Try it

A cart, a stop line, and a wrong mass

\[ \text{real: } \ddot p = \frac{u}{m}, \quad u = \tilde m\,a,\quad \tilde m = 1\,\text{kg}, \quad \class{mx-bad}{s = m/\tilde m} \qquad B = 3\,\text{m} - p \] \[ \text{rule: } \class{mx-cbf}{\ddot B + 4\dot B + 4B \ge 0} \quad \text{model: } \widetilde{\ddot B} = -a \quad \text{real: } \ddot B = -\tfrac{a}{s} \quad \text{patched: } \hat{\ddot B} = -a + \class{mx-rl}{\beta + \alpha a} \]

The cart wants to cruise at 3 m/s (ades = 2(3 − v)). The QP picks the a closest to ades that passes the rule. The "learned" α, β come from a straight-line fit on the model-only run's data (the paper does this fit with RL).

Limits

When it fails

  • Assumes the CLF built for the model is still a valid CLF for the real robot. Large errors can break this.
  • Measured V̇ and B̈ come from numerical derivatives, which are noisy on real hardware. All results are in simulation.
  • The QP can have no solution when rules conflict. This happened much less after training, but nothing guarantees it.
  • My note, not the paper's: safety now depends on α, β being right. Nothing proves they are right in every state; the evidence is simulation runs.

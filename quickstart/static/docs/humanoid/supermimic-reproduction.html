SuperMimic reproduction

A Unitree G1 motion tracker trained through a learned world model, rebuilt from the paper alone. The authors released no code.

G1 · 29 joints LAFAN1 · 40 clips · 2.45 h MuJoCo Warp via mjlab 1× RTX 5080 16 GB

One training iteration

STEP 1 · SIMULATOR

Collect

2,048 simulated G1s track clips with the current policy plus small action noise. Each step goes into a replay buffer.

STEP 2 · WORLD MODEL

Fit the model

A 3×2048 MLP learns the next body state from state, action, and the robot's friction, encoder bias and torso mass offset. Trained on 8-step windows of its own predictions.

STEP 3 · POLICY

Learn in imagination

The policy acts 32 steps inside the frozen model. The return is backpropagated through the model into the policy. A critic estimates what comes after.

start state from the buffer32 × 0.02 s = 0.64 s imaginedcritic

The simulator never needs gradients: they flow only through the learned model.

Watch it

Write a video to videos/<clip>.mp4
.venv/bin/python visualize.py runs/lafan1_16gb/ckpt_054000.pt --clip dance1_subject2
Open an interactive MuJoCo window instead (needs a screen)
.venv/bin/python visualize.py runs/lafan1_16gb/ckpt_054000.pt --clip jumps1_subject1 --live

Other options: --start-s and --seconds pick the segment, --resync-s 0 lets the dream run with no correction.

Run it

Set up (isolated venv; don't share site-packages)
python3 -m venv .venv && .venv/bin/pip install mjlab==1.6.0
Convert the 40 LAFAN1 CSVs to 50 fps motions
.venv/bin/python convert_lafan1.py
Self-checks: reward matches mjlab, state encoding round-trips, 3 iterations run
.venv/bin/python test_supermimic.py
Train (first run compiles for ~9 min)
.venv/bin/python train.py --preset 16gb --out-dir runs/lafan1
Score a checkpoint on every clip
.venv/bin/python evaluate.py runs/lafan1/ckpt_054000.pt

What the paper didn't specify

Everything in the paper's equations and tables is followed as written. These are the biggest gaps I filled; README.md lists all of them.

DetailChoice hereWhy
Simulatormjlab's BeyondMimic G1 taskThe paper builds on BeyondMimic in MuJoCo Warp; one author co-wrote mjlab.
Model state14 tracked bodies + 29 joints (240 numbers)Enough to compute reward and observation exactly.
Model framePelvis heading frame, predicts the changeOne model works anywhere on the floor.
Learned partsDynamics and fall prediction; reward is computedA computed reward can't be gamed by the policy.
Goal inputNext 10 reference frames: joints, joint speeds, torso tiltBeyondMimic's no-state-estimation setup.

Moving to the H200

  • Drop --preset 16gb. The defaults are the paper's sizes: 4,096 robots, 4,096 imagined rollouts, 1,000-step buffer.
  • Peak memory is 7.4 GB at the reduced sizes. Paper sizes should fit the H200's 141 GB easily (estimate, not measured).
  • Same setup: an isolated venv with mjlab==1.6.0.
  • BONES-SEED (129,514 motions) then becomes practical, but it needs its own converter first.

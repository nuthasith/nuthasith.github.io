General Nonlinear Control Problem Sec. II • Eqs. (1a)–(4)
xk+1 = f(xk, uk, wk),    yk = h(xk, vk)
uk = πk(xk, rk)   s.t.   g(xk, uk) ≤ 0
xk ∈ ℝnx: State uk ∈ ℝnu: Input wk, vk: Process & sensor noise g(x,u) ≤ 0: State/input safety constraints
Nominal, Robust (ISS) & Stochastic Lyapunov Sec. III-A–C • Thms. 1–3
Nominal: ΔV(xk) ≤ −α3(‖xk − x̄‖)
ISS: ΔV(xk) ≤ −α3(‖xk − x̄‖) + σ(‖wk‖)
Stochastic: 𝔼[V(xk+1) | xk] − V(xk) ≤ −ℓ(xk) + c
V(x): Energy-like certificate σ(‖wk‖), c: Residual error from model mismatch / noise
Control Barrier Functions (CBF) & Safety Filters Sec. III-D • Forward Invariance
Safe Set: 𝒮 = { x ∈ ℝnx : b(x) ≥ 0 }
CBF Condition: b(f(xk, uk)) − b(xk) ≥ −α(b(xk))
Filter: minuk ‖uk − ukL‖²   s.t. xk+1 ∈ 𝒮 (or xT|k ∈ 𝒮f)
ukL: Arbitrary learned policy b(x) ≥ 0: Barrier certificate 𝒮f: Terminal invariant set (PSF)
Structured Dynamics Learning & GP Posterior Sec. IV-A & IV-D • Eq. (8)
f̂(x, u) = f̂n(x, u) + f̂l(z),    z = [x⊤, u⊤]⊤
GP: f̂l(z) ∼ 𝒢𝒫(μ̂(z), Σ̂(z)),   Tightening: ±β · σ̂(z)
f̂n: Known physics / nominal model f̂l(z): Data-learned residual β: Confidence scaling factor
Willems' Fundamental Lemma & Regularized DeePC Sec. V-A & V-D • Direct Data-Driven
[ Up⊤   Yp⊤   Uf⊤   Yf⊤ ]⊤ α = [ uini⊤   (yini+σy)⊤   u⊤   y⊤ ]⊤
minα, u, y, σy ∑ ℓ(uk, yk) + λα‖α‖22 + λσ‖σy‖22
Up, Yp, Uf, Yf: Hankel data matrices α ∈ ℝN−L+1: Trajectory weights λα, λσ: Noise/nonlinear regularizers
Reinforcement Learning (RL) & Bayesian Optimization (BO) Sec. VI-A–D • Policy & Tuning
RL: minθ J(θ) = −𝔼πθ [ ∑k=0∞ γk r(xk, uk) ]
BO: θn+1 = arg maxθ∈Θ αEI(θ | 𝒟n),   J(θ) ∼ 𝒢𝒫(μJ, σJ2)
πθ: Parameterized policy αEI(θ): Expected Improvement acquisition function
